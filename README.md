# 사진 일기

아이폰 홈 화면에 추가해서 쓰는 사진 중심 개인 일기장 (웹앱).

## 아이폰에 설치
1. Safari로 앱 주소를 연다.
2. 아래 공유 버튼 → '홈 화면에 추가'.
3. 홈 화면의 아이콘으로 연다. (홈 화면 앱과 Safari는 기록을 따로 보관한다.)

## 백업
설정 → `YYYY년 백업하기` → `파일로 저장하기` → '파일에 저장'으로 iCloud Drive에 보관.
복원은 설정 → `백업 불러오기`에서 zip 파일을 고른다 (그 연도 기록이 백업 내용으로 바뀐다).

## 개발
```
npm install
npm run dev     # 같은 와이파이의 폰에서 열려면 표시되는 Network 주소 사용
npm test
npm run build
```
앱 이름은 `src/config.ts`의 `APP_NAME`에서 바꾼다.
